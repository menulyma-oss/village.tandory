# Village Tandoori Menu

A self-contained, multilingual restaurant menu for Village Tandoori. The site is plain HTML, CSS, and JavaScript, with local image assets and no build dependencies.

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Set **Framework Preset** to **Other**.
3. Use the repository root as the **Root Directory**.
4. Leave **Build Command** empty.
5. Leave **Output Directory** empty; if Vercel requires a value, use `.`.
6. Deploy. No environment variables are required.

The repository root must contain `index.html` and the `images` directory.
